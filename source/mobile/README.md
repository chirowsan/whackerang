# Boomerang Brawl — native wrappers (Capacitor 6)

`mobile/` wraps the same single-file web build (`../build.mjs --app` -> `www/index.html`) as a native
**Android** app and an **iOS** Xcode project. All free: no paid accounts needed.

| Platform | Status |
|---|---|
| Android APK | **Built and signature-verified on the dev box** (not run on a physical device or emulator there). `../android/BoomerangBrawl.apk` (release, self-signed) and `../android/BoomerangBrawl-debug.apk` |
| iOS | **Source prepared only. NOT built, NOT tested** (needs a Mac + Xcode; this repo was prepared on Linux) |

## Android — build

Prereqs: JDK 17, Android SDK platform 34 + build-tools 34.0.0, Node 18+.

```bash
export JAVA_HOME=/path/to/jdk-17 ANDROID_HOME=/path/to/android-sdk
# optional release signing (local keystore, never commit it):
keytool -genkeypair -keystore ~/bb-release.jks -alias boomerangbrawl -keyalg RSA -keysize 2048 -validity 10000
export KEYSTORE=~/bb-release.jks KSPW='your-keystore-password'
./build-android.sh          # -> ../android/BoomerangBrawl.apk + BoomerangBrawl-debug.apk
```

What the Android shell does: landscape-locked (`sensorLandscape`), immersive sticky fullscreen (system bars hidden,
re-hidden on focus), notch/cutout drawn edge-to-edge, `FLAG_KEEP_SCREEN_ON`, hardware-accelerated WebView, long-press/zoom/
overscroll disabled, audio without user-gesture requirement, haptics via `@capacitor/haptics`
(fallback `navigator.vibrate`), adaptive icon, dark splash.

### Install on a Samsung / any Android phone
1. Download `BoomerangBrawl.apk` from the GitHub Release on the phone.
2. Open it. Android will ask to allow **"Install unknown apps"** for your browser/Files app — allow it for this one install.
3. If Play Protect warns "unknown developer", choose *Install anyway* (the APK is signed with a self-generated key, not a Play Store key).
4. Updates: later APKs signed with the *same* keystore install over the top. A different key requires uninstalling first.

## iOS — build with a Mac + free Apple ID (not done on this box)

Requirements: macOS, Xcode 15+, CocoaPods (`sudo gem install cocoapods` or `brew install cocoapods`), Node 18+, an iPhone/iPad + cable.

```bash
cd mobile
npm install
npm run sync            # builds ../ web assets into www/ and runs `npx cap sync` (also runs `pod install`)
npx cap open ios        # opens ios/App/App.xcworkspace in Xcode
```

In Xcode:
1. Select the **App** target -> *Signing & Capabilities* -> tick *Automatically manage signing* -> Team: **your free Apple ID** (add it under Xcode > Settings > Accounts).
2. Change the **Bundle Identifier** to something unique (e.g. `com.yourname.boomerangbrawl`) — free accounts cannot reuse `com.chirow.boomerangbrawl` if someone else has it.
3. Plug in the iPhone, trust the Mac, enable *Settings > Privacy & Security > Developer Mode* on the phone, pick the device, press **Run**.
4. First launch: on the phone go to *Settings > General > VPN & Device Management* and trust your developer profile.

Free-account limits (Apple's, not ours): the app expires after **7 days** and must be re-run from Xcode; max 3 sideloaded apps; no
TestFlight/App Store (those need the paid $99/yr program). The iOS project is set to landscape only, status bar hidden,
`isIdleTimerDisabled = true` (screen stays awake). Alternatively, the **PWA** (Safari > Share > Add to Home Screen) needs no Mac or account.

## Layout
- `capacitor.config.json` — appId `com.chirow.boomerangbrawl`, name *Boomerang Brawl*, webDir `www`
- `android/` — Gradle project (MainActivity does immersive/keep-awake/WebView tuning)
- `ios/` — Xcode project (Pods are generated on the Mac by `cap sync`)
- `www/` — generated by `node ../build.mjs --min --app`
